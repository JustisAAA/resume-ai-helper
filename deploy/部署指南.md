# 腾讯云轻量服务器部署指南（实战版）

> 基于 2026-08-15 实际部署经验总结
> 服务器：49.232.34.64（Ubuntu 24.04 + Docker 29 镜像）
> 项目：简历面试AI助手（resume-ai-helper）

---

## 一、购买服务器

1. 打开 https://cloud.tencent.com/act/campus （云+校园学生专区）
2. 实名认证（25岁以下免学籍认证，直接买）
3. 选择：**轻量应用服务器 2核2G**（约¥74/年）
4. **操作系统选：Ubuntu 24.04-Docker 29**（自带Docker，省去安装）
5. 地域选离你最近的（北京/上海/广州）

---

## 二、服务器初始化

### 1. 重置密码
- 控制台 → 实例 → 更多 → 密码/密钥 → 重置密码
- 设置 root 密码（也用于 ubuntu 用户登录）
- **必须重启实例**让密码生效

### 2. 放行防火墙端口（关键！）
控制台 → 实例 → **防火墙** → 添加规则：
- 协议：TCP
- 端口：**3002**（Web访问）+ **22**（SSH，默认已开）
- 来源：`0.0.0.0/0`
- 策略：允许

---

## 三、连接服务器

### 方式1：腾讯云网页终端（最简单）
控制台 → 实例 → 登录 → 用户 `ubuntu` + 密码

### 方式2：本地 SSH
```
ssh ubuntu@你的公网IP
```
（Windows cmd 自带 ssh，无需安装）

> ⚠️ 提示符是 `ubuntu@VM-xx:~$`，不是 root

---

## 四、获取代码

### 情况A：GitHub 公开仓库（推荐）
```bash
# 国内服务器直连 GitHub 会超时，用镜像加速
git clone https://ghfast.top/https://github.com/JustisAAA/resume-ai-helper.git
```

### 情况B：私有仓库
```bash
# 用带 token 的方式
git clone https://用户名:token@github.com/JustisAAA/resume-ai-helper.git
```

### 情况C：拉取最新更新
```bash
cd ~/resume-ai-helper
git fetch https://ghfast.top/https://github.com/JustisAAA/resume-ai-helper.git main
git reset --hard FETCH_HEAD
```

## 五、修改配置

```bash
cd ~/resume-ai-helper/deploy
nano docker-compose.yml
```

需要改的位置（**已改为真实值，一般不用再动**）：
- `POSTGRES_PASSWORD` 和 `DATABASE_URL` 里的密码（2处一致）
- `JWT_SECRET`（随机长字符串）
- `YUANQI_APPID/APPKEY/ENTERPRISE_APPID/ENTERPRISE_APPKEY`（腾讯元器密钥）

> ⚠️ nano 快捷键：`Ctrl+W`搜索、`Ctrl+O`保存、`Ctrl+X`退出
> ⚠️ 腾讯云网页终端里 Ctrl+W 会被浏览器拦截（关闭标签页），**尽量少用搜索**，直接方向键移动

---

## 六、构建镜像（首次10分钟，之后2-3分钟）

```bash
cd ~/resume-ai-helper
sudo docker compose -f deploy/docker-compose.yml build
```

> 需要 sudo（ubuntu 无 Docker 权限）。加组免 sudo：
> ```bash
> sudo usermod -aG docker $USER && exit  # 重新登录生效
> ```

### 常见构建错误（已修复的坑）

| 报错 | 原因 | 解决 |
|------|------|------|
| `Could not find Prisma Schema` | postinstall 在 schema 复制前跑 | Dockerfile 已用 `--ignore-scripts` 修复 |
| `Unsupported platform ... musl` | alpine 镜像缺 glibc | Dockerfile 已改为 `node:22-slim` |
| apt-get 很慢（600秒+）| Debian 源访问慢 | 正常现象，耐心等 |

## 七、启动服务

```bash
sudo docker compose -f deploy/docker-compose.yml up -d
sudo docker compose -f deploy/docker-compose.yml logs -f app
```

## 八、初始化管理员账号

> ⚠️ Dockerfile 启动命令只执行 `prisma db push`（建表），**没有执行 seed**，所以管理员账号不会自动创建！

```bash
cd ~/resume-ai-helper
sudo docker compose -f deploy/docker-compose.yml exec app npx ts-node prisma/seed.ts
```

成功看到：
```
✅ 管理员账号创建成功
   邮箱：admin@admin.com
   密码：admin123
```

> ⚠️ 必须在 `~/resume-ai-helper` 目录下执行（docker-compose.yml 相对路径）

```bash

# 数据备份（数据库）

```

## 十一、关键提醒

1. **数据持久化**：数据库和上传文件在 Docker 卷里，重启不丢；但**换服务器=数据丢失**，需备份迁移
2. **密钥安全**：docker-compose.yml 含真实密钥，**不要提交到公开仓库**！建议改为环境变量方式
3. **管理员密码**：seed 是默认密码 admin123，上线后请修改
4. **GitHub 访问**：国内服务器 clone/pull GitHub 必须用 `ghfast.top` 镜像，直连会超时
5. **镜像更新**：改代码后必须重新 build（不只是 up -d），否则跑的还是旧代码
