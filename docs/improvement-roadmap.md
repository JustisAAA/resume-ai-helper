## 3. 技术改进路线

### 3.1 安全改进（P0优先级）

#### 🔒 改进7：JWT存储方式改造

**当前方案问题**：
```typescript
// 当前：Token存储在localStorage（XSS风险）
localStorage.setItem('token', token);
```

**改进方案**：
```
方案A：HttpOnly Cookie（推荐）
- Token存储在HttpOnly Cookie
- JavaScript无法读取，防XSS
- 需要后端配合设置Cookie

方案B：Token加密存储
- Token加密后存localStorage
- 增加解密成本，但可防XSS
```

**实施步骤**：
1. 后端修改登录接口，返回Set-Cookie头
2. 前端移除localStorage操作
3. 添加CSRF防护（Double Submit Cookie）

---

#### 🔒 改进8：文件上传安全加固

**当前问题**：
- 只检查文件扩展名，不检查MIME类型
- 无文件大小限制（依赖前端限制，可被绕过）

**改进方案**：
```typescript
// 后端添加MIME类型验证
const fileFilter = (req, file, cb) => {
  const allowedMimes = ['application/pdf', 'application/vnd.openxmlformats...'];
  if (allowedMimes.includes(file.mimetype)) {
    cb(null, true);
  } else {
    cb(new Error('不支持的文件类型'), false);
  }
};

// 添加文件大小限制
const upload = multer({
  limits: { fileSize: 10 * 1024 * 1024 }, // 10MB
  fileFilter
});
```

### 3.2 性能改进（P1优先级）

#### ⚡ 改进9：数据库查询优化

**当前问题**：
```typescript
// 问题示例：N+1查询
const interviews = await prisma.interview.findMany({ where: { userId } });
for (const interview of interviews) {
  const messages = await prisma.message.findMany({ 
    where: { interviewId: interview.id } 
  });
  // N+1问题：每个interview都查询一次
}
```

**改进方案**：
```typescript
// 使用include一次性加载关联数据
const interviews = await prisma.interview.findMany({
  where: { userId },
  include: { messages: true } // 一次性加载所有messages
});

// 添加复合索引
model Interview {
  @@index([userId, status, createdAt])
}
```

#### ⚡ 改进10：前端代码分割与懒加载

**当前问题**：
- 所有页面打包在一个bundle.js
- 首屏加载慢（预计>2MB）

**改进方案**：
```typescript
// 使用React.lazy()按需加载页面
const InterviewRoom = React.lazy(() => import('./pages/InterviewRoom'));

function App() {
  return (
    <Suspense fallback={<Loading />}>
      <Routes>
        <Route path="/interviews/:id/room" element={<InterviewRoom />} />
      </Routes>
    </Suspense>
  );
}
```

**预期收益**：
- 首屏加载时间减少60%+
- 用户体验提升
