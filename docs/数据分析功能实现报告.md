# 数据分析功能实现报告

**日期**：2026-06-06  
**任务**：将Dashboard图表移出，新增独立"数据分析"页面  
**需求来源**：用户反馈Dashboard图表太占空间，建议放到新增功能里

---

## 一、需求分析

### 1.1 问题描述
- Dashboard首页包含三个图表（招聘漏斗、申请趋势、职位热度），占据大量屏幕空间
- 用户希望Dashboard保持简洁，图表放到独立功能页面

### 1.2 解决方案
- 新增独立页面 `EnterpriseAnalytics.tsx`（`/enterprise/analytics`）
- 将三个图表从Dashboard移至数据分析页面
- Dashboard添加"数据分析"快捷入口按钮
- 顶部导航栏添加"数据分析"入口

---

## 二、实现内容

### 2.1 新增文件

#### `frontend/src/pages/EnterpriseAnalytics.tsx`
**功能**：独立的数据分析页面，展示三个图表

**页面结构**：
```
- 顶部导航栏（返回按钮 + Logo + 导航链接 + 退出登录）
  - 职位管理
  - 申请管理
  - 面试列表
  - 数据分析（当前页，高亮）
  - 退出登录
- 主内容区
  - 招聘漏斗图（BarChart）
  - 申请趋势图（LineChart，最近7天）
  - 职位热度排行（BarChart）
- 加载状态（ spinning图标）
- 错误状态（错误提示 + 返回首页按钮）
```

**API调用**：
- `enterpriseAPI.getDashboardStats()` - 获取图表数据

**图表说明**：
| 图表 | 类型 | 数据来源 | 说明 |
|------|------|----------|------|
| 招聘漏斗 | BarChart | `dashboardStats.funnel` | 职位→申请→面试→录用 |
| 申请趋势 | LineChart | `dashboardStats.applicationTrend` | 最近7天每日申请数 |
| 职位热度 | BarChart | `dashboardStats.jobPopularity` | Top5职位申请数排行 |

## 五、后续建议

### 5.1 功能增强
1. **图表交互**：点击图表元素跳转到对应列表（如点击"申请"柱状图跳转到申请列表）
2. **时间范围选择**：申请趋势图支持选择时间范围（7天/30天/90天）
3. **导出报告**：数据分析页面添加"导出PDF"按钮，生成数据报告
4. **实时刷新**：添加"刷新"按钮，手动刷新数据

### 5.2 UI优化
1. **图表颜色**：统一图表配色方案（当前漏斗图紫色、趋势图紫色、热度图绿色）
2. **空状态**：当没有数据时显示空状态提示（而不是空白图表）
3. **加载骨架屏**：图表加载时使用骨架屏而不是spinning图标

### 5.3 性能优化
1. **数据缓存**：dashboardStats数据缓存5分钟，避免频繁请求
2. **图表懒加载**：滚动到图表区域再加载（当前是页面加载时全部请求）
