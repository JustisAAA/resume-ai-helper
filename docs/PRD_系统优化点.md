# PRD - 简历面试AI助手系统优化点

**文档版本**: v1.0
**创建日期**: 2026-06-05
**产品经理**: 许清楚（Alice）
**项目**: 简历面试AI助手 - 系统优化

---

## 一、产品目标

本次系统优化旨在提升"简历面试AI助手"的整体用户体验和系统性能，核心目标包括：

1. **提升系统性能**：优化面试报告生成速度和首页加载速度，减少用户等待时间
2. **增强报告可读性**：改进面试报告的视觉呈现，突出关键信息，增加可视化图表
3. **改善面试引导**：提供清晰的进度指示和下一步引导，减少用户在面试过程中的迷失感
4. **完善报告分享功能**：支持报告便捷分享给第三方（HR/面试官），提供分享链接和导出功能
5. **加强输入验证与安全性**：补齐前端输入验证，防范XSS/注入风险，增加API频率限制

---

## 三、需求池

### P0 - 必须有（核心优化）

#### 1. 性能优化：面试报告生成速度提升

**功能描述**：
- 优化AI调用逻辑，支持流式响应，减少报告生成等待时间
- 面试报告页面增加加载状态提示，避免用户以为系统卡死
- 优化后端AI API调用，增加超时处理和降级策略（模拟模式兜底）

**验收标准**：
- [ ] 报告生成时间从当前（假设10-15秒）降低到3-5秒内可见首字
- [ ] 流式响应下，用户能看到实时生成的内容
- [ ] AI调用超时时自动降级到模拟模式，不阻塞用户

**技术要点**：
- 后端 `/api/interviews/:id/report` 改为Streaming响应
- 前端使用EventSource或fetch + ReadableStream接收流式数据
- 增加超时配置（AI API timeout: 30s）

---

#### 2. 性能优化：首页加载速度提升

**功能描述**：
- 优化首页数据加载逻辑，减少不必要的API调用
- 首页静态资源增加缓存策略
- 延迟加载非关键资源（如底部功能介绍）

**验收标准**：
- [ ] 首页首屏加载时间 < 2秒（网络正常情况下）
- [ ] 用户已登录时，直接跳转Dashboard，不展示首页内容

**技术要点**：
- 检查 `Home.tsx` 的 `useEffect` 逻辑，已登录用户应直接跳转
- 静态资源设置Cache-Control头
- 代码分割：非首屏组件使用React.lazy()

---

#### 3. 输入验证与安全性：前端输入验证

**功能描述**：
- 所有用户输入框增加前端验证（长度限制、特殊字符过滤）
- 面试回答输入框限制最大长度（如5000字符）
- 简历上传限制文件类型和大小（PDF/DOCX，最大10MB）

**验收标准**：
- [ ] 输入验证在前端和后端双重执行
- [ ] 特殊字符（如`<script>`）被过滤或转义，不产生XSS
- [ ] 文件上传有类型和大小限制，超出时给出明确提示

**技术要点**：
- 前端：使用表单验证库（如react-hook-form + zod）或手动验证
- 后端：所有API输入使用Prisma ORM（防SQL注入），输出使用DOMPurify清理
- 文件上传：multer配置limits和fileFilter

---

#### 4. 输入验证与安全性：API频率限制

**功能描述**：
- 为关键API增加频率限制（如登录、注册、AI调用）
- 使用express-rate-limit中间件
- 频率超限时返回429状态码和明确错误信息

**验收标准**：
- [ ] 登录API：同一IP 15分钟内最多5次尝试
- [ ] AI调用API：同一用户每分钟最多20次请求
- [ ] 频率限制触发时，返回友好的错误提示

**技术要点**：
- 安装 `express-rate-limit`
- 在 `backend/src/index.ts` 或各路由文件中添加rate limit中间件
- 配置keyGenerator（按IP或按用户ID）

## 五、待确认问题

### 5.1 报告分享的权限控制

**问题**：分享链接的报告，是否允许被分享者下载PDF或再次分享？

**选项**：
- A. 只允许在线查看，不允许下载和再次分享（最安全）✅ **已确认**
- B. 允许下载PDF，但不允许再次分享
- C. 允许下载和再次分享（最开放）

**决策**：采用方案A，最大程度保护原作者隐私

---

### 5.2 AI调用频率限制的具体数值

**问题**：AI调用API的频率限制应该设置为多少？

**选项**：
- A. 每分钟10次（较严格，防止滥用）
- B. 每分钟20次（较宽松，适合高频使用）✅ **已确认**
- C. 动态调整：根据用户套餐设定

**决策**：MVP阶段采用方案B（每分钟20次），后续根据用户反馈调整

---

### 5.3 面试报告生成的流式响应实现方式

**问题**：流式响应应该使用SSE（Server-Sent Events）还是WebSocket？

**选项**：
- A. SSE：实现简单，单向通信，适合报告生成场景✅ **已确认**
- B. WebSocket：双向通信，但实现复杂，需要额外库支持

**决策**：采用方案A（SSE），符合报告生成的单向数据流特性

---

### 5.4 前端输入验证的实施方案

**问题**：前端输入验证应该使用第三方库（如zod）还是手动实现？

**选项**：
- A. 使用zod + react-hook-form：功能强大，类型安全，但增加bundle大小✅ **已确认**
- B. 手动实现：轻量，但开发效率低，容易遗漏边界情况

**决策**：采用方案A，长期来看收益大于成本

---

### 5.5 报告导出PDF的样式保真度

**问题**：导出PDF时，是否需要完全还原网页样式？还是使用简化样式？

**选项**：

### 6.1 性能优化：流式响应实现（SSE）

**后端修改**（`backend/src/routes/interview.ts`）：

```typescript
// 新增：生成报告（流式）
router.get('/:id/report/stream', authMiddleware, async (req: Request, res: Response) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  
  try {
    const interview = await prisma.interview.findFirst({...});
    
    // 调用AI API（流式）
    const response = await axios.post(AI_API_URL, {
      agent_id: process.env.YUANQI_AGENT_ID,
      stream: true,
      messages: [...]
    }, {
      responseType: 'stream'
    });
    
    let buffer = '';
    response.data.on('data', (chunk: Buffer) => {
      buffer += chunk.toString();
      const lines = buffer.split('\n');
      buffer = lines.pop() || '';
      
      for (const line of lines) {
        if (line.startsWith('data: ')) {
          const dataStr = line.slice(6);
          if (dataStr === '[DONE]') {
            res.write('data: [DONE]\n\n');
            res.end();
            return;
          }
          try {
            const data = JSON.parse(dataStr);
            const content = data.choices?.[0]?.delta?.content;
            if (content) {
              // 转发 OpenAI 兼容格式给前端
              res.write(`data: ${JSON.stringify({
                id: data.id,
                object: 'chat.completion.chunk',
                created: data.created,
                choices: [{ index: 0, delta: { content } }]
              })}\n\n`);
            }
          } catch (e) {
            console.error('Parse SSE chunk failed:', e);
          }
        }
      }
    });
    
    response.data.on('end', () => {
      if (!res.writableEnded) {
        res.write('data: [DONE]\n\n');
        res.end();
      }
    });
  } catch (error) {
    res.write(`data: ${JSON.stringify({ error: '生成失败' })}\n\n`);
    res.end();
  }
});
```

**前端修改**（`frontend/src/pages/InterviewReport.tsx`）：

```typescript
// 使用EventSource接收流式数据
const eventSource = new EventSource(`/api/interviews/${id}/report/stream`);
eventSource.onmessage = (event) => {
  if (event.data === '[DONE]') {
    eventSource.close();
    return;
  }
  const data = JSON.parse(event.data);
  if (data.chunk) {
    setReportText(prev => prev + data.chunk);
  }
};
```

```typescript
import rateLimit from 'express-rate-limit';

// 登录限制：15分钟内最多5次
export const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5,
  message: { error: '尝试次数过多，请15分钟后再试' },
  standardHeaders: true,
  legacyHeaders: false,
});

// AI调用限制：每分钟最多20次
export const aiLimiter = rateLimit({
  windowMs: 60 * 1000,
```
