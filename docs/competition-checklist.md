#### 00:20-00:50 简历上传与分析
**屏幕内容**：ResumeUpload.tsx → ResumeDetail.tsx

**操作要点**：

**屏幕内容**：ToolsMatch.tsx

## 5. 现场展示准备

### 5.1 现场设备测试清单

**到达现场后第一时间检查**：

- [ ] **投影仪**：连接笔记本，测试分辨率（推荐1920×1080）
- [ ] **音响**：播放演示视频，测试声音清晰度
- [ ] **网络**：打开网页，测试速度和稳定性
- [ ] **灯光**：讲台灯光是否刺眼？能否看清屏幕？
- [ ] **麦克风**：测试无钱/有线麦克风，确保声音清晰
- [ ] **翻页笔**：测试翻页笔是否工作，备用电池
- [ ] **座位**：评委座位是否能看清屏幕？需要调整吗？

### 5.2 演讲技巧

#### 身体语言

| 要点 | 说明 | 常见错误 |
|------|------|---------|
| **站姿** | 站讲台一侧，不要挡屏幕 | 站屏幕正中间 |
| **眼神** | 扫视所有评委，不要只看一个人 | 只看PPT或稿子 |
| **手势** | 指向屏幕重点，自然放松 | 手插口袋或交叉胸前 |
| **移动** | 适度移动，不要太僵硬 | 站着不动或走来走去 |

#### 语速与停顿

| 要点 | 说明 | 练习方法 |
|------|------|---------|
| **语速** | 稍慢于平时说话，清晰发音 | 录音自己听，调整语速 |
| **停顿** | 重点内容后停顿2秒，让评委消化 | 在PPT上标注"停顿"提示 |
| **强调** | 关键词加重语气，可重复一遍 | 练习时拍手或在桌上敲一下提醒自己 |

### 5.3 应急方案

#### 网络故障

**预案A**：切换到手机热点
- 提前测试手机热点速度和稳定性
- 现场快速切换（练习过，<30秒完成）

**预案B**：播放演示视频
- 提前录制完整演示视频（5分钟版本）
- 现场播放视频 + 同步解说

**预案C**：展示截图 + 口头讲解
- 准备关键页面的截图（10-15张）
- 截图快速切换 + 详细讲解

#### AI API故障

**预案**：切换到Mock模式
- 后端已支持`USE_MOCK_AI=true`环境变量
- 提前测试Mock模式演示效果
- 现场快速切换（修改.env + 重启后端，<1分钟）

#### 设备故障时

**预案**：使用备份笔记本
- 备份笔记本同样的演示环境
- 快速切换（HDMI拔插，<30秒）

### 8.2 答辩中注意事项

#### 评委提问环节

**黄金法则**：
1. **听清问题** - 如果不清楚，礼貌请评委重复一遍
2. **思考3秒** - 不要立即回答，思考组织语言
3. **分点回答** - "第一...第二...第三..."结构清晰
4. **不知为不知** - 不会的问题坦诚说"这方面我们确实考虑不足，赛后会研究"
5. **保持礼貌** - 即使评委质疑，也要微笑回应"您提的这个问题很好，我们之前确实没从这个角度思考过"

**禁忌**：
- ❌ 打断评委说话
- ❌ 与评委争论
- ❌ 贬低竞品或他人工作
- ❌ 说"这个不重要"或"我们没时间做"

## 附录：答辩心理调节技巧

### 紧张怎么办？

**上台前（候场）**：
- 深呼吸：吸气4秒 → 憋气4秒 → 呼气4秒（重复3次）
- 积极心理暗示："我已经准备得很充分了"、"评委也是普通人"

**上台后（开场）**：
- 先环视评委3秒，微笑，再开始说话
- 开口第一句放慢语速，建立自信节奏

**问答环节**：
- 如果不记得答案，说"这个问题很好，让我们团队思考一下"
- 如果实在答不出，说"这方面我们的确还有不足，赛后会深入研究，感谢您提出这个问题"

### 忘词怎么办？

**预防措施**：
- PPT备注栏写关键词提示
- 打印PPT讲义版（每页6张），手拿讲稿（但不要一直看）
- 提前演练10遍以上，形成肌肉记忆

**应急方案**：
- 不要愣住，自然说"让我看看PPT下一页"（争取时间回忆）
- 或转向评委互动："各位评委老师，对于这个部分，大家有什么想了解的吗？"（转移注意力）
