# 管理员端功能报告

## 概述

管理员端是 MyGo 平台的系统管理后台，供超级管理员使用。管理员可以查看系统整体运营数据（用户数、企业数、职位数、面试数等），管理全平台用户账号（查看/搜索/封禁/删除），以及处理用户举报（审核通过或驳回）。管理员端拥有最高权限，可跨角色管理所有用户类型（求职者、企业用户、HR 子账号、管理员）。

## 功能模块清单

| 功能 | 页面文件 | API文件 | 描述 |
|------|---------|--------|------|
| 管理后台布局 | AdminLayout.tsx | — | 通用后台布局组件（顶部导航 + 侧边栏 + 主内容区） |
| 系统概览 | AdminDashboard.tsx | api.ts (adminAPI.getStats) | 展示系统统计数据卡片（用户数/企业数/职位数/面试数/举报数等） |
| 用户管理 | AdminUsers.tsx | api.ts (adminAPI.getUsers/updateUser/deleteUser) | 用户列表展示、搜索、角色筛选、状态筛选、封禁/解封、删除用户 |
| 举报管理 | AdminReports.tsx | reportAPI.ts (getList/approve/reject) | 举报列表查看、状态筛选（待处理/已通过/已驳回）、处理举报（通过/驳回） |

| 路由 | 页面组件 | 描述 |

## 业务流程

### 1. 系统监控流程
管理员登录后进入系统概览 → 查看总用户数、今日新增用户、企业数、今日新增企业、职位总数、总申请量、面试数、报告数、待处理举报数等统计指标 → 点击统计卡片可导航到对应管理页面

### 2. 用户管理流程
进入用户管理页面 → 默认展示全量用户列表（分页，每页10条） → 支持按关键词搜索、按角色（求职者/企业/HR/管理员）筛选、按状态（正常/封禁）筛选 → 对违规用户可执行封禁/解禁操作 → 对需要清理的用户可执行删除操作 → 操作后自动刷新列表

### 3. 举报处理流程
进入举报管理页面 → 查看举报列表（含举报人、被举报人、举报原因、描述、状态、时间） → 按状态（待处理/已通过/已驳回）筛选查看 → 对"待处理"的举报进行审核 → 选择"通过"（确认违规）或"驳回"（举报无效） → 处理后状态更新，举报人可见处理结果

## 权限控制

- **未登录用户**: 无法访问任何管理页面，自动重定向到 `/login`
- **已登录但非管理员用户**: 自动重定向到 `/dashboard`（求职者首页）
- **管理员（ADMIN）**: 可访问所有管理页面，拥有最高权限
- **JWT 认证**: 所有 API 请求通过 `Authorization: Bearer <token>` 鉴权
- **主题适配**: 管理员端暂用企业端主题（`documentElement.dataset.role = 'enterprise'`）
